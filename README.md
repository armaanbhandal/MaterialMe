# MaterialMe

An Android app (Java) that shows a scrollable list of sports cards built with RecyclerView and Material Design components.

## Features

- Card list of 11 sports, each with an image, title and description
- Tap a card to open a detail screen
- Swipe a card left or right to dismiss it
- Drag cards up and down to reorder them
- Floating action button resets the list
- Images loaded with Glide

## Running it

Open the folder in Android Studio and run the `app` configuration on an emulator or device (Android 6.0+).
